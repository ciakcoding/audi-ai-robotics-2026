# Robot model source

The Unitree G1 MJCF and mesh assets in `assets/` come from the official
[Google DeepMind MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie/tree/main/unitree_g1).

This project uses the 29-actuator `g1.xml` model with fixed rubber-hand visual
meshes. The articulated five-finger variant is intentionally excluded.

The upstream model license is preserved at `assets/UNITREE_G1_LICENSE`.
