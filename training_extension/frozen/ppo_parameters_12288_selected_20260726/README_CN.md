# 冻结 PPO 参数残差模型（累计 12,288 投篮）

这是 2026-07-26 在 1 点截止前完成并选中的真实 RL 策略。

## 训练谱系

- PPO 1,024：首次正向检查点；
- PPO 4,096：此前冻结版本；
- PPO 4,096 -> 12,288：seed 2053，学习率 `1e-5`；
- 从其中最好的 10,752 -> 12,288：seed 2054，学习率 `3e-6`、
  clip `0.015`、target KL `0.002`；
- 网络更新设备：RTX 4060 Laptop GPU；
- 轨迹采样：8 个 CPU MuJoCo 子环境；
- 每 512 个完整投篮保存一次检查点。

尝试 16 个 CPU 环境时 Windows multiprocessing 在环境初始化阶段发生
`BrokenPipeError/EOFError`，没有开始训练；因此正式精修使用已验证稳定的
8 环境配置。

## 同一 300-seed 评估

| 策略 | 成功 | 平均穿圈误差 | 最大误差 | 篮板 | 跌倒 |
|---|---:|---:|---:|---:|---:|
| CEM v17 | 293/300 | 3.865 cm | 38.514 cm | 0 | 0 |
| 旧 PPO 4,096 | 294/300 | 3.545 cm | 39.141 cm | 0 | 0 |
| **新 PPO 12,288** | **297/300** | **3.336 cm** | **31.255 cm** | **0** | **0** |

新模型相对旧 PPO：

- 成功数增加 3；
- 平均误差下降约 5.9%；
- 最大误差下降约 20.1%。

相对 CEM v17，平均误差下降约 13.7%，成功数增加 4。

## 不变合同

- 篮圈中心 `(2.2, 0.0, 1.2)`；
- 球心穿越有效半径 `0.10 m`；
- 必须下降穿越篮圈；
- 禁止篮板球、扣篮、伸手入圈和根节点平移作弊；
- 保留两步走路、下蹲、腿部发力、投球、随挥和恢复；
- 释放距离、飞行距离、手到篮圈距离、稳定性与跌倒检查不变。
